# Changelog

All notable changes to Recova are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-21

### Added
- Screen, monitor and window capture with live source thumbnails.
- Microphone and Windows system audio, mixed with Web Audio; mic level meter, volume and test.
- Optional facecam, recorded as a separate track.
- 720p/1080p/1440p at 30/60 FPS with capability checks.
- Countdown, capture-excluded floating toolbar, pause/resume, stop and discard.
- Disk-streamed recording with crash recovery.
- Local library with thumbnails, playback, rename, reveal and delete.
- Video Studio with 15 templates, 10 layouts, custom backgrounds, aspect ratios, facecam styling and text overlays.
- Background MP4 (H.264/AAC) export with progress, ETA and cancel.
- Settings for recording, camera, export and the application.
